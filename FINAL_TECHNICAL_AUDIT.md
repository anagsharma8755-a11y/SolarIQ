## 9. Known Limitations

### Architecture

1. **LOD-1 only** — Flat-roof box buildings. LOD-2 data model exists but generation is not implemented.
2. **No shading integration** — `ShadingAnalyzer` module exists but results are not used in scoring.
3. **Heuristic solar scoring** — Not physics-based irradiance model. Uses 50% orientation, 30% tilt, 20% surface type.
4. **Static energy estimation** — Uses global defaults (1700 kWh/m², 80% coverage, 20% efficiency), not site-specific.

### ML

5. **No trained model** — Adapter stub only. No training data included.
6. **No model files** — `models/` directory is empty.

### Data

7. **Synthetic sample data** — All sample files are development data, not real observations.
8. **Weather pipeline output not consumed** — Pipeline exists but results are not used by the solar engine.

### API

9. **No authentication** — All endpoints publicly accessible.
10. **No rate limiting** — No per-IP throttling.
11. **No background jobs** — Large analyses block the request thread.

### Dependencies

12. **FastAPI deprecation warnings** — `on_event` is deprecated in favor of lifespan handlers.
13. **`utcnow()` deprecation** — `datetime.utcnow()` should use timezone-aware objects.

## 14. Conclusion

**The SolarIQ backend is functional and demonstrable.** The system successfully:

1. Processes building geometry through a single-pass analysis pipeline
2. Scores surfaces for BIPV solar suitability
3. Estimates energy production potential
4. Ranks surfaces using transparent multi-factor optimization
5. Aggregates results at city scale
6. Exposes all functionality via a well-documented REST API
7. Includes security hardening, structured logging, and Docker deployment
8. Passes 601 tests with 0 failures

**What it does NOT do:**
- Train or serve ML models (adapter ready, model absent)
- Use real-world irradiance data (heuristic fallback)
- Account for shading (module exists, not integrated)
- Authenticate requests (development-mode only)

**These limitations are documented honestly** in `docs/LIMITATIONS.md` and should be disclosed during SIH presentation.
